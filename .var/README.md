# Generated runtime state

Local, generated data that must stay out of Git. Only this README and the `.gitkeep` placeholders are tracked.

| Folder | Contents |
| --- | --- |
| `runs/<run-id>/` | Evaluation results, latency, cost, and traces; see [evals/README.md](../evals/README.md) |
| `cache/` | Disposable caches that tools can rebuild |

Delete anything here when it is no longer needed. Never store credentials.
